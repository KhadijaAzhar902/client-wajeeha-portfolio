# Wajeeha Dawood — Executive Support Portfolio

A custom, responsive personal portfolio for **Wajeeha Dawood**, designed around a quiet-luxury executive-support aesthetic for Administrative Assistant, Personal Assistant and Executive Assistant opportunities in Dubai.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- No framework or build step required

## Key Interactions

- Interactive **Executive Mode** portrait with cursor-reactive lighting and capability labels
- Responsive mobile tap interaction for the portrait
- Expandable **Executive Desk** capability rows
- Scroll-reactive **A Day in Motion** timeline
- Animated Microsoft Office tool visuals
- Magnetic buttons and custom desktop cursor
- Scroll reveals and frosted navigation
- `prefers-reduced-motion` support

## Run Locally

Open this folder in VS Code and launch `index.html` using **Live Server**, or open `index.html` directly in a browser.

## Deployment

This is a static site and can be deployed directly to Netlify, GitHub Pages or any static hosting provider.

For Netlify, use the repository root as the publish directory. No build command is required.
